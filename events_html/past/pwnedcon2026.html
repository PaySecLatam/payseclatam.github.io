SEPTIEMBRE 2026 · GUATEMALA CITY, GUATEMALA

Pwned!CON 2026

PaySec Latam // Payment Security Village

En Pwned!CON 2026 presentamos tres demostraciones prácticas sobre tecnologías de pago contactless: ataques de relay NFC, un simulador de cobros en transporte público, y lectura de datos de documentos de identidad con comandos APDU.

Demostraciones

📡 Ataques de Relay NFC

Demostración en vivo de ataques de relay sobre NFC. Se mostró cómo es posible retransmitir la señal de una tarjeta contactless a distancia sin que el portador lo note, con el objetivo de entender el riesgo real de este tipo de ataques en sistemas de pago y acceso.

  • → Arquitectura del ataque (proxy + ghost)
  • → Hardware utilizado
  • → Mitigaciones reales en producción

🚌 Simulador de Cobros — Estación de Buses

Simulador que replica el sistema de cobro de una estación de transporte público para comprender cómo se procesa el pago con distintos tipos de tarjetas. Se demostró el flujo completo de cobro con tres tipos de tarjeta:

  • 📶 Tarjeta RFID estándar
  • 🔵 Tarjeta DESFire
  • 💳 Tarjeta real de transporte

⬡ El simulador será liberado como open-source próximamente.

🪪 Lectura de DPI con Comandos APDU

Demostración de lectura de datos del Documento Personal de Identificación (DPI) de Guatemala usando comandos APDU directamente sobre la misma aplicación utilizada en las demos anteriores. Se exploró la estructura del chip y la información accesible usando la misma autenticación que nos proporcionan las aplicaciones oficiales.

  • → Estructura de archivos del chip
  • → Comandos APDU de lectura
  • → Datos públicos vs. datos protegidos
